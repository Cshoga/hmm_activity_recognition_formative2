# HMM Human Activity Recognition

- `data/` – one labelled CSV per recording (`<activity>_<nn>.csv`; columns: time, seconds_elapsed, acc_x/y/z, gyr_x/y/z). iPhone XR, Sensor Logger, ~99.4 Hz.
- `prepare_data.py` – merges the raw Sensor Logger zips into `data/`.
- `hmm.py` – NumPy Gaussian HMM (supervised fit, Viterbi).
- `hmm_activity_recognition.ipynb` – full pipeline (features, HMM, heatmap, decoded sequences, evaluation).
- `figures/`, `results/` – outputs generated by the notebook.

To Run: `pip install numpy pandas matplotlib seaborn jupyter`
